# SkillBridge Extra & Offline Documentation

This directory contains offline reference materials, project specifications, and supplementary resources for SkillBridge.

## Directory Contents

- **`docs/SkillBridge_AI.pdf`**: Master Product Requirement Document (PRD) detailing the 5-factor scoring algorithm, technical interview flow, ATS audit metrics, and database schema specifications.
- **`docs/SkillBridge_Interview_Handbook.pdf`**: Local interview preparation guide.

*Note: Production code resides in the root directory and standard Django application packages.*
